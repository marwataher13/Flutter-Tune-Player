# 🎵 Tune App

### *A Simple Interactive Musical Experience*

---

## 📝 Description
**Tune App** is a fundamental Flutter application designed to master UI layout and audio integration. The app features a clean, vertically-segmented interface where each segment represents a different musical note, providing immediate auditory feedback upon interaction.

## ✨ Key Features
* 🎹 **Musical Interaction:** 7 distinct color-coded bars, each linked to a specific musical tone.
* 🌈 **Dynamic UI:** Utilizes a structured layout to ensure perfectly aligned and responsive segments.
* 🎧 **Audio Playback:** Seamless integration of audio assets for a smooth user experience.

## 🛠️ Tech Stack & Concepts
* **Framework:** [Flutter](https://flutter.dev) 🚀
* **Language:** [Dart](https://dart.dev)
* **Packages:** `audioplayers` for sound management.
* **Core Concepts:** * Modular Code (Creating reusable Widgets).
    * Asset Management.
    * Expanded & Flex layouts.

## 💡 Learning Objectives
This project was built to solidify the basics of:
1. **Refactoring:** Breaking down the UI into smaller, reusable components.
2. **Event Handling:** Capturing user taps to trigger specific actions (Playing Sound).
3. **Logic Separation:** Managing lists of colors and sounds efficiently.
